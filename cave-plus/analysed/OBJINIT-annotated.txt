================================================================================
OBJINIT FILE - ANNOTATED VERSION
Initial Object and Creature Placement for Cave-Plus
================================================================================

This binary file (256 bytes) contains the initial placement of all 42 objects
and creatures in the game. Each entry is a 4-byte little-endian integer.

FORMAT:
  Byte 0:       Room number (0-70)
  Bytes 1-3:    Initial stamina/health for creatures (0 for items)

SPECIAL ROOMS:
  Room 1:  Altar (where Staff of Merlin can be charged)
  Room 19: Mortuary (where dead creatures go)
  Room 20: Armoury (where exorcised objects are moved)
  Room 56: Bank (where treasure can be deposited)

ROOM DISTRIBUTION ANALYSIS

Most Populated Rooms:
- Room  1 (Altar):    6 items/creatures (Dragon, Staff, Amulet, Treasure, Guardian x2)
- Room 20 (Armoury):  6 items/creatures (Ruby, Shield, Spider, Viper, Drunk, Guardian)

- Room 26: Snake pit!

Empty Rooms:
- Many rooms (6, 7, 9, 10, 12, 16-19, 21-25, 27-31, etc.) start empty
- Rooms 16-20 are in "wizard's domain" (special area)

================================================================================
NOTES ON STAMINA VALUES
================================================================================

There's a discrepancy between initial stamina (in OBJINIT) and base health
(in data file). The game likely uses:
- OBJINIT stamina: Starting health when game begins
- Data file health: Health when creature is deployed/respawned

Some creatures have much higher initial stamina than their base health,
suggesting they were manually placed with boosted stats for game balance.

The Goblin with 65535 HP appears to be a bug or intentional "unkillable"
creature for testing/easter egg purposes.
