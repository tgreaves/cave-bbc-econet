Format for each entry:

INITIAL PLACEMENT:
  Initial room locations and starting stamina are stored in the OBJINIT file
  (see OBJINIT-annotated.txt for complete placement details)

OBJECT PROPERTY STRING FORMAT (for items):
  - Empty string for simple objects
  
CREATURE PROPERTY STRING FORMAT (CCMs - Computer Controlled Monsters):
  Position 1:     Behavior flag (A=Aggressive, B=Passive)
  Position 2-4:   Attack chance (0-999, checked against activity level)
  Position 5-7:   Secondary attack chance (only if Aggressive)
  Position 8-10:  Teleport chance (0-999, multiplied by 100)
  Position 11-13: Follow chance (0-999, divided by 1000)
  Position 14-15: Attack type code (see attack types below)
  Position 16-18: Base damage (randomized: damage + RND(damage)/2)
  Position 19:    'H' marker
  Position 20-22: Health/Stamina points

ATTACK TYPE CODES:
  01 = Message
  02 = Hit
  03 = Cave collapse
  04 = Award points
  05 = Poison
  06 = Stab
  07 = Update
  08 = Teleport
  09 = Force command
  10 = Bite
  11 = Burn
  12 = Zap
  13 = Shoot
